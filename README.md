# Food Ordering Management System

A simple **Food Ordering Management System written in C**. This project is a menu-driven program that allows users to view the food menu, place orders, check their current order, and generate the final bill.

### Features

* Display available food items and prices
* Place food orders with quantity
* View current order
* Calculate total bill automatically
* Simple and easy-to-use menu-driven interface

### Concepts Used

* C Programming
* Structures
* Arrays
* Functions
* Loops and Conditional Statements
* Switch-Case
* String Handling

This project is created as a basic **BCA C programming project** to understand how real-world ordering systems can be implemented using basic programming concepts.
